# 外部资料索引

本目录不再直接保存厂商上位机、DLL、设备固件、完整手册和个人课程报告，以避免仓库膨胀、隐私泄露及不明确的再分发授权。

复现项目时可能需要以下外部资料：

| 设备或工具 | 曾使用的资料 | 获取建议 |
| --- | --- | --- |
| Xiaomi CyberGear 微电机 | 通信协议、参数说明、调试器和电机固件 | 从电机官方渠道或授权供应商获取当前版本 |
| ECU | 中文帮助文件、CAN 数据定义、断火与补油配置说明 | 从 ECU 厂商或授权经销商获取 |
| AS32-DTU-1W 数传电台 | 产品手册、配置工具和模式说明 | 从泽耀科技官方产品页获取 |
| VOFA+ | 串口示波器 | 从 VOFA+ 官方渠道下载 |
| SWD/DAP 下载器 | 产品手册与驱动 | 从对应硬件厂商获取 |

## 使用外部资料时的记录要求

新增或更新资料索引时，请记录：

- 资料名称。
- 厂商与设备型号。
- 版本号或发布日期。
- 官方来源链接。
- 访问日期。
- 许可证或再分发条件。

如果资料允许公开再分发，也应优先保留官方链接；只有项目运行必须、来源明确且许可证允许的文件才考虑纳入仓库。
