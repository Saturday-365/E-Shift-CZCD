# 硬件与机械说明

## 当前设计源文件

`2_HardWare` 包含：

- STM32F407 核心板 M.2 V1.0。
- HQU15 集成板 V1.0。
- HQU15 集成板 V2.0。
- HQU15 集成板 V3.1。

文件格式为嘉立创 EDA `.epro`。V3 PCB 曾出现 CAN 收发器接地不良问题，当前更推荐从 V3.1 开始检查和复用。

`3_3DProject` 包含 Fusion 360 `.f3d` 源文件：

- 换挡拉杆。
- 两版电机支架面板。
- 离合拉线盘。

## 复用前检查

- 根据自己的发动机、车架和电机重新核对孔位与干涉。
- 核对 PCB 电源输入范围、线宽、保险和反接保护。
- 核对 CAN 收发器供电、电平、地连接和终端电阻。
- 电机靠近发动机安装时，评估热传导与过温保护阈值。
- 支架需要按最大换挡力和冲击载荷重新校核。
- 线束应满足振动、防水、应力释放和赛车维修需求。

## 待补充的开放制造文件

为了让没有嘉立创 EDA 或 Fusion 360 的贡献者也能使用，后续版本应补充：

- 原理图 PDF。
- PCB Gerber、钻孔文件、BOM 与坐标文件。
- 关键网络和连接器引脚表。
- 机械 STEP/STL/DXF 导出文件。
- 材料、厚度、公差与加工说明。
- 各硬件版本的变更记录。

在这些文件完成核对前，仓库中的设计应视为参考工程，而不是可直接量产的成品。
