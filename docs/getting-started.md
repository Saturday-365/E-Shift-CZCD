# 构建与台架验证

## 1. 环境准备

- STM32CubeMX 6.12.0。
- STM32CubeF4 V1.28.1。
- Keil MDK，ARMCC V5.06 Update 7 Build 960。
- Keil STM32F4 Device Family Pack 2.17.1。
- ST-Link 或兼容 SWD 下载器。
- 带限流功能的台架电源、急停开关和可靠的机械限位。

版本来自当前 `.ioc` 和 `.uvprojx`。如果使用其他版本，请在 Issue 或测试记录中写明。

## 2. 构建

1. 打开 `1_SoftWare/Eshift_byCyberMotor_F407/MDK-ARM/STM32F407VET6_CUBMX.uvprojx`。
2. 确认目标器件为 STM32F407VETx。
3. 确认 Device Pack 已安装。
4. 执行 Build。
5. 编译产物不会提交到仓库；如需对外发布 HEX，应放入 GitHub Release 并标注对应提交。

如果需要修改外设，在 CubeMX 中打开 `.ioc`，完成配置后重新生成。不要直接修改 CubeMX 生成的外设初始化代码。

## 3. 上电前检查

- 换挡机构与发动机动力断开。
- 电机输出轴不会撞击机械极限。
- 台架电源已设置合理电流限制。
- 急停能够直接切断执行器电源。
- CAN_H、CAN_L、地线和终端电阻连接正确。
- CAN1 为 1 Mbit/s，CAN2 为 500 kbit/s。
- CyberGear ID、转动方向和当前位置已确认。
- ECU 输出帧格式与 `SA_CANDataprocess.c` 一致。

## 4. 分级验证

### A. 控制器空载

1. 不连接电机和 ECU，仅给控制器供电。
2. 检查程序启动与指示灯状态。
3. 模拟拨片输入，确认不会出现连续误触发。

### B. 电机空载

1. 固定电机但不连接换挡拉杆。
2. 设置较低速度、扭矩和电源限流。
3. 验证零位、正反方向与回零动作。
4. 触发超时条件，确认能够退出换挡流程。

### C. 机构台架

1. 连接换挡拉杆，但保持发动机停机。
2. 逐档标定动作角度。
3. 记录位置、力矩、温度、目标档位和实际档位。
4. 连续执行升降档，检查支架变形、松动和过温。

### D. 车辆低能量测试

只有 A～C 均通过后才能进入车辆测试。首次测试应关闭自动断火、补油和离合联动，先验证单次换挡，再逐项启用功能。

## 5. 测试记录最小要求

每次测试至少记录：

- 日期、地点与测试人员。
- 固件提交哈希。
- PCB 与机械版本。
- 电机型号、固件、ID 和限制参数。
- ECU 固件与 CAN 配置。
- 如产生测试数据，记录文件名或归档链接。
- 预期结果、实际结果和异常现象。
- 下一步修改以及验证结论。
